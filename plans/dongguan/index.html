03

FREEDIVE FIRST

不是来挑战 46 米，
是来学会安全下潜

0M5M12M AIDA246M POOL
新手的成功标准不是“潜得最深”，而是平压舒适、动作稳定、懂得救援，并知道什么时候该结束一次下潜。
  • 永不单独闭气，酒店泳池也不例外。
  • 耳压不通立刻上升，不顶痛。
  • 未通过就补课，不为一张证硬闯。
  • 深度日之后休息、补水、不喝酒、不长途骑车。
查看 AIDA 要求、费用边界和询价模板
04

MOTORCYCLE: CONDITIONAL

可以喜欢摩托，
但先尊重东莞的路

STOP

市区 / 跨城默认不骑

不发布绕禁行路线，不用无牌、改装或无保险车辆，不上高速去深圳 / 惠州。

CHECK

把路线发给官方确认

通过东莞交警官方渠道或 12345 问清拟走道路，并让租车方书面确认。

GO — ONLY IF

白天短环线

正确驾照 + 正规牌证保险 + 合同 + 护具 + 干燥天气 + 身体已恢复，全部满足才启用。

查看法规证据与替代交通
05

SEE + SHOOT

东莞不是无聊，
只是景点散得很诚实

GARDEN

可园

岭南园林的框景、廊桥与水面。清晨或雨后最稳，周二闭馆。

HISTORY

虎门遗址群

先看展览，再到威远炮台读珠江口。预约状态出发前重查。

INDUSTRY

鳒鱼洲

红砖、钢架、旧电厂与水岸蓝调，适合工业复古和环境肖像。

LAKE

松山湖外景

公共湖岸拍桥、倒影与远处建筑；没有员工接待不进华为办公园区。

VILLAGE

南社古村

祠堂、水塘、灰塑、砖雕。适合半日慢拍，不和莞城线硬串。

SCENT

沉香文化

寮步香市和中国沉香文化博物馆，理解“莞香”而不只看工厂城市。

查看博物馆开放状态、机位与拍摄边界
06

EAT BY DISTRICT

按镇街吃，
比追一张网红榜靠谱

厚街 · 烧鹅濑粉大岭山 · 荔枝柴烧鹅道滘 · 肉丸粥道滘 · 裹蒸粽莞城 · 茅根粥万江 · 水乡菜

要预约

东莞老饭店、松山湖酒店餐厅、周末晚餐、包间、整鹅和时令菜。

通常现场吃

食得福烧鹅濑粉、永锋肉丸粥、糖水、佳佳美裹蒸粽零售；仍要防售罄。

课程日怎么吃

训练前清淡不过饱，训练后补水、碳水和蛋白，不喝酒，不用夜宵透支第二天。

打开具体店铺、菜品和预约分级
